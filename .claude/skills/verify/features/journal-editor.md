# Journal editor

A full-screen page for one day's journal entry: free text blocks and prompt blocks (a purple question over an answer), a bar above the keyboard with an `Ask me something` pill, a `Questions` menu of the fixed prompts and the word count. It autosaves into `JournalEntry` (one row per day, `ZBLOCKSJSON` of blocks) and the entry's day is the app day, which ends at 05:00.

## Sub-features

- `je-open` the editor opens for today from the Today book button (`Journal`; not drawn while the dark card shows) or the dark journal card (`Start writing` / `Keep going · N words`), from the Calendar day sheet (`Write about this day`, shown only for a day with no entry and not after today; a day with an entry shows the night card, whose `Read` opens the reader and whose `Edit` opens the editor), from the entries page (`Tonight, in progress`, only for a draft of today that is not done and with no search query), from the reader's pencil, and from Trends' `Write tonight's entry` (only on the locked Trends page). The dark Today card also shows at any hour once the day is cleared, with `Written · N words` after Done and a `Last night · N words` link (opens the reader) while today has no entry.
- `je-type` typing writes a text block; the header label runs `Saving…` → `Saved just now` (about 10 s) → `Saved`, and the bar counts `N words`. A done entry that is reopened reads `Reopened · saved` until the first change, and a failed write reads `Couldn't save`.
- `je-chip` the `Questions` menu (a pill with a chevron, right of `Ask me something`) lists the four fixed questions, `Favorite moment`, `Grateful for`, `Low energy felt like`, `Tomorrow`; picking one inserts a fixed prompt at the cursor and the cursor lands in the new answer. A question already in the entry shows a check and is disabled. (The id keeps the old chip name; the chips themselves are gone.)
- `je-keys` Return at the end of an answer starts a new text block; Backspace in an empty answer removes the prompt; each question has a small visible `x` beside it (accessibility label `Remove question`) that removes it, and a long-press on the question offers `Remove question` too; either way the answer stays as text.
- `je-ask` the `Ask me something` pill inserts a model question (`source: llm`; the model is asked for 10 s, and asked once more for 5 s on a copy when Core rejects the answer as closed, as claiming something was done early without support, or as too long; the editor prewarms the model when it opens; the model is never called when the system language is Chinese) or, when the model is unavailable or fails, a question about the day (`source: fixed`, no `fixedKey`, e.g. `“<open quest>” is still open. What got in the way today?`) with the toast `Here's one about your day.`, and only when the day offers nothing fresh, the first missing fixed prompt with `Here's a standard one.`; five model prompts cap it (`Enough questions for one night`; the pill dims to 0.4 and a hint line shows above the bar); writing that holds a safety word (in text blocks or answers, never in questions; checked after the cap) gets a safety card instead of a question. While a request is out the pill shows a spinner and ignores taps; if the cursor's block is gone when the answer lands the toast reads `No question added.` (with every fixed question already in the entry, `You've used every standard question.`).
- `je-done` `Done` is the only button: it writes the page, marks an entry that has writing in it done (`ZDONEAT` set once and never cleared: reopening and tapping `Done` again keeps the first time) and closes. There is no `Close`. The page does the same when it disappears, so leaving it any other way also marks the entry; an unfinished draft (`ZDONEAT` NULL) now exists only while the editor is open or after the app was backgrounded (which only flushes the write) or killed with it open. An entry with only whitespace is deleted and nothing is marked.
- `je-hand-off` the Apple Journal hand-off sends a finished day once at 05:00 through the user's Shortcut. Device only; the Debug page has a simulator stand-in.

## How to get to it (user POV)

- Today tab → book button (about 342, 92 pt; by day only), or the dark journal card (20:00 to 05:00, or once the day is cleared). Calendar → a day → `Write about this day →`.

## Driving it with the simulator

Preconditions: `V up --fresh`. Debug → `Journal model` says `available` on this simulator, so `Ask me something` calls the real on-device model unless you force a result.

- **Open.** Tap the book button, or the dark card's button when the card shows and the book is not drawn (or Calendar → today's cell → `Write about this day`). The header reads a save label (`Saved`) at the left and `Done` at the right (no `Close`); the heading `Wednesday, October 7 · today` by day (`· tonight` from 20:00 to 05:00, no suffix for a past day); the cursor is in an empty page; the bar at the bottom reads `Ask me something`, `Questions`, `0 words`. `V sql "select count(*) from ZJOURNALENTRY"` is 0: opening writes nothing.
- **Type.** Type `hello world today` and wait about 2 s. The label reads `Saved just now` and the bar `3 words`. `V sql "select ZDAYKEY, ZBLOCKSJSON, ZDONEAT is null from ZJOURNALENTRY"` returns one row for the app day, `[{"id":"…","text":"Hello world today","type":"text"}]` (the first letter is capitalised by the keyboard), draft `1`.
- **Questions.** Tap `Questions` (the pill right of `Ask me something`; the chip coordinates of earlier passes, 284, 580 with the keyboard up and 893 without, belonged to the old chip row and no longer hold, so read the pill from a screenshot), tap `Favorite moment` in the menu and type `a quiet walk`. A purple question `What was your favorite moment today?` appears over the answer, the menu row shows a check and is disabled on the next open, the bar reads `6 words`. The JSON gains `{"answer":"A quiet walk","fixedKey":"favoriteMoment","question":"What was your favorite moment today?","source":"fixed","type":"prompt"}`.
- **Ask.** Tap `Ask me something` (about 107, 580 pt with the keyboard up, 893 without). With the model available a question tailored to the day appears at the cursor (observed: `What got in the way of your planned job applications today?`), stored with `"source":"llm"` and no `fixedKey`, and the cursor sits in its empty answer. The wording is the model's, so assert the block, not the text.
- **Safety.** Type a safety word in an answer (observed with `feeling hopeless`), **wait a second so the text has landed**, then tap the pill: a card `That sounds heavy. This is only a journaling tool and can't help the way a person can. If you might hurt yourself, please reach out to someone you trust or a local crisis line.` with `Got it` appears and nothing is inserted (block count unchanged). Tap `Got it` (about 52, 505 pt with the keyboard up, 818 without). Driven again on 2026-10-07 with `feeling hopeless` appended to an answer: the card appeared, the entry kept 2 blocks, `Got it` closed it, and `Done` set `ZDONEAT`; the reader then showed `8 words`, `3 quests done`, `Normal energy`.
- **Remove a question (driven by the owner 2026-10-12).** Tap the small `x` at the right of a purple question: the question goes and its answer stays as a text block (the JSON loses the `prompt` block and gains a `text` one). A long-press on the question offers `Remove question` as well.
- **Done.** Tap `Done` (about 382, 92 pt; it is the only button in the header). When opened from a Calendar sheet it returns to that sheet; `ZDONEAT` is now set (`select ZDONEAT is not null from ZJOURNALENTRY` is `1`), the sheet's night card reads `THAT NIGHT <time> · 8 words`, and Trends counts the day. Unanswered prompts persist (the reader shows `Not answered`).
- **Forced results (Debug, simulator only; driven 2026-10-12 with `Error`).** Settings → Debug → `Ask me something (simulator only)` (below `Journal time`, about three swipes down; the pills sit at about y = 541 pt once that section is mid-screen: `Real`, `Question`, `Timeout`, `Error`, then `Garbage` on a second line): `Question` gives a canned question; `Timeout` spins the pill about 10 s and then falls back; `Error` and `Garbage` fall back at once. The fallback is the day question first: on a fresh day with an open quest, typing `Walked by the river after work.` and tapping the pill inserted `“Say no to something” is still open. What got in the way today?` (`"source":"fixed"`, no `fixedKey`) with the toast `Here's one about your day.` (worded `Couldn't reach the guide, here's one about your day` on the 2026-10-12 build before the toasts were shortened), and `Favorite moment` stayed unticked in the `Questions` menu. Only a day with nothing fresh to ask about gets the fixed questions, in the order Favorite moment, Grateful for, Tomorrow, Low energy felt like (`Here's a standard one.`; with all four present `You've used every standard question.`). Debug's `Journal model` card then reads `Last ask: <date> at <time> · the model …` (what became of the last tap: no model, timed out, threw or answered nothing, rejected and why, answered on the second ask). The forced setting outlives `Erase all records…`; set it back to `Real` when done.
- **Journal time (driven).** Debug → `Journal time (simulator only)` (about 173, 393 pt for `Evening`, 80 for `Real`): `Real / Evening / Daytime / Cleared`. `Evening` forces the clock to 21:00, `Daytime` and `Cleared` to 12:00 (`Cleared` also treats the day as cleared). It drives the Today card, the editor's date line, the entries page card title and the Trends button. Under `Evening`: Today shows the card (`tonight`, `Keep going · 2 words`), the editor reads `Monday, October 5 · tonight`, Trends reads `Write tonight's entry`. By day the same surfaces read `today` / `Today, in progress` / `Write today's entry`. Put it back on `Real` afterwards.

## Gotchas

- **The `text` tool returns before every character has landed.** A pill tap straight after typing sent the request without the new word and inserted a question instead of the safety card; the second tap (after the text had landed) showed the card. Wait a second between typing and any tap that reads the text.
- On a freshly installed simulator the first time the keyboard appears iOS shows a `Speed up your typing by sliding your finger across the letters` panel over the lower half of the screen with a `Continue` button (about 220, 907 pt); tap it before typing, or the first characters go nowhere.
- The editor is one `UITextView` per block: tap into the block, then type. It focuses the end of the last block on open.
- Return in free text inserts a plain newline; only Return at the very end of an answer makes a block. Save-time normalisation drops empty text blocks and joins adjacent text blocks with a newline; a prompt alone does not make an entry.
- Toasts fade after 4 s and the model can answer in a few seconds: screenshot quickly (`V shot`, not the control tool).
- Fixed questions from the `Questions` menu do not count toward the cap of 5; only model prompts do.
- The Apple Journal Shortcut (`Get Journal Text to Send`, `Create Journal Entry`, the 05:00 Personal Automation) cannot run here; Debug → `Journal hand-off (simulator only)` → `Run Get Journal Text to Send now` calls the same hand-off at the shifted clock (the day must be written one day behind: `V day 1` first; a second press returns nothing). Real Apple Journal, Share sheet contents and the model's wording quality need a device.
- The switch `Send my writing with the question request` (default on) lives on Settings → `Journal & reminders`, section `Ask me something` (caption "Lets the question see what you've written so far. Off: it only sees today's quests."); it only changes the request text and has no visible effect with a forced result.
- Debug → `Ask evaluation (simulator only)` → `Run` sends 4 samples of 15 made-up days through `JournalAsk.resolve` on the real model and writes `ask-eval-<time>.json` / `.md` into the app's Documents; it stores nothing in the app and writes nothing when the model is unavailable. Not driven.
- Once (2026-10-12), tapping the pill right after the control tool's `text` action returned left a stray text block `" b"` after the inserted question; the same sequence with a 2 s wait between typing and the tap did not. Wait before tapping, and read `ZBLOCKSJSON` rather than trusting the screen when a block looks odd.
- The `today` / `tonight` wording follows the hour only (the real clock, or the 21:00 / 12:00 that `Journal time` forces); time travel (`V day N`) moves the day key but never the hour, so it never changes the wording. The editor fixes its wording when it is built, so it does not flip mid-session.
